# Independent Framework Verification

`FrameworkTests.csproj` compiles the package runtime and generated fixture only.
It does not reference `Assets/Game` or any game rules. `CoreTests.csproj` remains
the optional existing-consumer regression suite.

`UnityConsumer` is a small independent Unity project, with its own UPM manifest.
It installs `Distributions/com.game.json-0.4.0.tgz`, not the development package
directory. The fixtures are regenerated by `scripts/verify-framework-unity.ps1`.
The script can run Editor, Mono or IL2CPP verification. IL2CPP builds use High
managed stripping and Development allocation markers.

Current evidence is in `Packages/com.game.json/VERIFICATION.md`. Raw execution
logs and reports live in `Artifacts`; they are intentionally not required source
dependencies. The first independent installation/build used an equivalent
temporary consumer at `Artifacts/PackageSmoke`; its test source has been retained
here for reproducibility. The source test project is not a new game or UI demo.

Each runtime check captures the old snapshot, prepares and commits a new version,
rejects stale and repeated publication, verifies cross-table old-row isolation,
calibrates allocation recording and reads the generated views 200,000 times.

`BenchmarkTests.csproj` compares the generated compact facade with strongly typed
DTO arrays plus Dictionary indexes, including a pooled-string DTO variant. All
backends consume identical values and the same precomputed query IDs. Three
scales contain 3,000 / 30,000 / 300,000 records. Dense mixed reads, sparse hits,
missing IDs and sequential scans are independently checked and timed. Load
timing uses five interleaved rounds; queries use seven; allocation measurement
runs separately from timing. Input buffers are excluded from post-full-GC
retained managed graph estimates, which are not process peak memory.

```powershell
dotnet run --project Tests/BenchmarkTests.csproj -c Release
powershell -ExecutionPolicy Bypass -File scripts/pack-framework.ps1
powershell -ExecutionPolicy Bypass -File scripts/verify-framework-unity.ps1 -Target IL2CPP -Benchmark
```

The Unity script copies the same benchmark source into the independent consumer.
The .NET baseline uses Newtonsoft.Json; the Unity baseline uses JsonUtility.
Unity records GC.Alloc event counts, never marker durations as bytes. A zero
event count after successful calibration supports zero allocated bytes on the
tested hot path; nonzero byte totals are unavailable (-1) in Unity reports.
Both timings exclude allocation instrumentation. The generated fixture is in
its own assembly and has no linker preservation directive; benchmark JSON DTO
reflection is preserved only in the separate consumer assembly.
